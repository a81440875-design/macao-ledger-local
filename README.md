# 記賬・本機

澳門幣個人帳本，可加入 iPhone 主畫面。空白帳本開始，毋須登入。

## 功能

- 每日快速記帳、MPay／信用卡／現金等付款方式、帳戶餘額。
- 首頁分類預算袋、超支提示、上月比較、自訂分類。
- 自訂每月／每年固定開支，預填後可核對修改。
- 自訂找卡數日期；只係 App 內提示，冇背景推送。
- 儲錢目標、保費付款月份、可用金額安全線。
- 手動輸入投資持倉、價格、目標比例；配置試算、月結同買賣記錄。
- 匯出流水、投資持倉、投資月結、投資買賣同月度快照 CSV。
- 完整 JSON 備份／還原，以及還原前嘅本機副本。

## iPhone 第一次使用

1. 用 Safari 打開已發佈網址，唔好用私密瀏覽。
2. 「分享」→「加入主畫面」，再由主畫面打開「記賬・本機」。
3. 喺「設定」核對銀行、MPay、現金同未還卡數；冇使用嘅戶口可填 0。
4. 喺「預算」設定自己嘅分類金額。設定只影響所選月份；月尾可沿用上月預算。
5. 固定開支、找卡數日期、保費同投資目標由自己設定，冇預填任何人嘅私人金額。

## 儲存同備份

帳目只存喺當前瀏覽器／主畫面 App。程式冇雲端同步、登入、銀行連接、分析追蹤或報價 API。首次載入需要網絡下載程式；成功建立離線快取後可以離線使用。託管服務仍會收到一般網站連線請求，但程式唔會上載你嘅帳目。

月尾去「設定」下載 CSV 同完整 JSON 備份，確認存入「檔案」→「我的 iPhone」。CSV 係閱讀／分析報表，唔可以用作完整還原；換機要將 JSON 備份傳去新手機，再喺「設定」匯入。清除網站資料、移除 App 或換機前先備份。只放喺同一部手機嘅備份，手機遺失時可能同時失去；可以自己再複製一份到電腦。

瀏覽器有機會回收本機儲存空間。內置本機還原副本亦會隨網站資料一併刪除，唔等於外部備份。

## 投資資料

月底價格要按券商月結單手動更新；冇即時或自動股價。持倉估值以 USD 記錄，MOP 換算匯率由自己設定。資產變化唔等於回報；投資月結用月初／月底總資產、入金同提款計算損益。配置建議只係按自己目標比例計算嘅數學試算，唔會落單。

## 用 GitHub Pages 發佈

1. 登入你嘅 GitHub 帳戶，建立一個新嘅 **Public** repository，例如 `macao-ledger-local`。
2. 上載呢個資料夾入面嘅檔案到 repository 最外層，確保 `index.html` 喺最外層。唔好只上載 ZIP 檔。
3. 開啟 repository **Settings → Pages**。
4. Source 揀 **Deploy from a branch**，Branch 揀 **main**，資料夾揀 **/(root)**，再 Save。
5. 等 GitHub 顯示已發佈嘅網址，再用 iPhone Safari 開啟。

GitHub Pages 免費方案使用公開程式庫。只上載本資料夾嘅程式，唔好加入帳本備份、CSV、私人 Excel、登入密鑰或其他個人資料。公開催入程式唔會令手機入面嘅帳目自動公開。

官方步驟：https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site

## 維護

所有檔案都係靜態 HTML／CSS／JavaScript，冇伺服器、資料庫或付費 API。沿用相同網址同儲存 key 更新；搬網址／改 repository 名之前先備份。每次更新程式亦應遞增 `sw.js` 嘅快取版本。GitHub 同一個網域嘅不同網站唔係安全隔離區，只應喺你信任同控制嘅帳戶託管。
